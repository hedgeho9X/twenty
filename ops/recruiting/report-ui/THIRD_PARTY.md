# Shadcn/ui source

Table, Card, Button and Badge were retrieved with `npx shadcn@latest view @shadcn/table @shadcn/card` and `view @shadcn/button @shadcn/badge` on 2026-11-01. Source style: registry/new-york-v4/ui. Imports of the `cn` registry dependency point to the local standard helper; responsibility comments were added. Component behavior is retained.
