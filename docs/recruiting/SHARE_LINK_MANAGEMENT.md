# 分享链接来源与操作

分享列表显示本次匹配的主体：人找岗时是候选人，岗找人时是岗位。对象名称链接回对应匹配结果；附加数量只显示实际分享的岗位或候选人，不拼接整批岗位名称。

匹配页手动生成分享、匹配结果文案自动生成分享，均传入 matchRunId。服务端检查当前身份可以读取来源匹配，并确认分享对象属于该匹配结果，然后把来源主体引用保存到原有私有缓存元数据。公开 token 仍只包含分享范围，不新增候选人身份或内部匹配信息。

旧链接没有来源元数据时保留原有效期及撤销行为，列表显示首个实际分享对象和数量，不凭空关联匹配。来源主体被删除后回退为同样的展示；不会因此让整个分享列表报错。

操作使用三个横排图标：眼睛预览、复制链接、红色方块撤销。按钮带可访问名称和悬浮标题，复制与撤销失败可见；撤销和复制串行，避免重复请求。

## 验证

- 来源关系校验、无来源旧链接、公开号资料最小化及撤销即时失效有服务端回归。
- 前端回归验证主体链接、简洁内容、三个图标按钮以及复制和撤销行为。
- 资料更新失效逻辑保留：缓存身份包含候选人、岗位、公司资料版本、协议及模型标识。读取时重新计算，不使用过期评分冒充新评分。
- 当前只读复核的两个最新 45 对组合任务均为 complete=true、stale=0、poolChanged=false，返回前十结果；“复用45项”不等于执行失败。用户截图中的旧失效提示当前接口未复现，不因此移除版本保护。
