# 材料解析与截图回归

## 1. 已运行的真实样本

Docling 2.145.0、RapidOCR及固定渲染器均在隔离本地容器运行。新增9个合成HTTP场景：中文双栏PNG、两页中文扫描PDF、两页DOCX、8页HTML、8页Markdown、外部资源HTML、AES-256加密PDF、损坏PDF、损坏DOCX，均按预期通过。旧DOC及中英Word的先前独立HTTP验证也已通过，仍需更广真实旧文件样本。

正向核对原件SHA、页数与预览数量一致、每张PNG完整、尾段标识和核心中英文职业文字；中文扫描识别后端工程师、TypeScript及PostgreSQL。截图完整覆盖与parser complete不等于逐字OCR准确，扫描和Word的尾标识需要按空白/下划线归一后核对。

## 2. 已修复的默认导出遗漏

第一轮发现扫描PDF的底部文字在截图可见，但默认Markdown导出未包含。现在明确导出Docling全部内容层，保留页眉页脚、备注和其他识别层，同时关闭多余下划线转义。解析协议标识升为docling-2.145.0-preview-v2；旧请求清单保持不可变，不用新结果悄悄覆盖旧版本。

修正后，两页扫描的尾部标识进入文字，HTML和Markdown最后一段均完整保留。页图仍全部生成并传后续材料分段，不以文字抽取替代原图。

## 3. 错误与隔离

加密PDF由pypdf 6.21.4生成，并先用正确密码独立打开核对两页，再验证无密码解析返回422。损坏PDF和DOCX同样拒绝，不能伪成功入库。需要上传可读取的原件；本轮不将候选人文件密码作为模型说明字段。

外部资源场景先从解析容器成功访问临时本地计数服务，证明资源可达，再提交同地址HTML。解析期间计数为0，脚本未执行，状态needs_review并报告缺失资源；不是仅用不可达域名推断网络隔离。

6项解析服务单元/真实渲染测试通过。首次失败报告、修正后9项报告及所有合成页图仅保存在.local/recruiting/parser-regression-v2和parser-output。复现生成器位于ops/recruiting/parser，真实HTTP执行器为ops/recruiting/smoke-parser.mjs。生成AES加密夹具的pypdf为测试工具，不新增应用运行依赖。

## 4. 评测版本边界

独立8人RSI第一轮冻结的原件文字来自preview-v1，未因本次修正重写。其报告不证明preview-v2、多模态或所有文字层准确；后续比较需要明确新输入/解析版本，并把已看过的8人称为回归集。
