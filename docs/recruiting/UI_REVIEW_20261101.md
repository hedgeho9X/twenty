## 2. 数据链路与边界

原链路：匹配列表回执只有主体名与进度，详情各行重复人选、当前公司展开和业务操作；文件只有受权下载。

现链路：匹配列表请求携带direction，服务端先过滤再分页，并从当前权限内的候选人资料返回expectedRoles；详情分别读取原生候选人职业字段、岗位JD和公司名称。悬停只读，不重新评分。候选人/JD读取仍走RecruitingRecordsService原生行/字段权限，不向前端发Token或新建公开文件链接。

原件通过既有受父任务权限约束的字节接口或页图接口读取。HTML作为转义文本，不放入可执行iframe；PDF使用已有页图或官方本地查看器；退出时撤销临时Blob URL。解析尚未生成的Word提示等待或下载，不能声称已能预览。
